# Тёплое место

Адаптивный демонстрационный сайт кофейни на русском языке. Чистые HTML, CSS и JavaScript, без библиотек и сборки.

## Как открыть

Дважды нажмите на файл `index.html` — сайт откроется в браузере. Также можно нажать на файл правой кнопкой мыши и выбрать «Открыть с помощью» → ваш браузер.

Для загрузки фотографий с Unsplash и шрифтов Google Fonts нужен интернет. Если шрифты недоступны, используются системные шрифты.

## Файлы

- `index.html` — тексты, меню, цены, контакты.
- `styles.css` — оформление и адаптация под смартфоны.
- `script.js` — фильтры меню и мобильная навигация.

Название, меню, цены и часы работы — демонстрационные. Адрес и телефон отмечены как примеры. Перед использованием для реальной кофейни замените сведения в `index.html`.
